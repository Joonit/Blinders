# Changelog

## 1.0.0 — first public release
- Dims everything except the active window, on every monitor (mixed DPI included)
- Spotlight mode (also dims the taskbar and always-on-top windows), keep-the-active-monitor-bright mode, fullscreen-aware
- Night schedule, accent border around the active window, tint colors, fade transitions, pause, background image
- Excluded apps, start with Windows, customizable hotkeys (default Ctrl+Alt+Win+…)
- Light / dark settings window that follows Windows, with a clickable, keyboard-accessible monitor map
- 30 built-in languages with right-to-left layout for Arabic, Persian and Hebrew; extra languages via `lang\*.ini`
- Settings in %APPDATA%\Blinders, or portable next to the exe
